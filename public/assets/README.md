# 商品 SVG 示意素材

這 8 張為本地手工 SVG 商品示意圖，不是原網站照片或正式品牌素材。商品文字、價格與庫存按使用者提供的截圖轉錄作 mock，不代表實際販售或庫存。圖片不載入任何外部資源。

可直接以使用者提供的 SVG 替換同名檔案：

- flash-salmon.svg：鮭魚
- flash-hotel.svg：溫泉旅宿
- flash-umbrella.svg：折疊傘
- flash-tissue.svg：衛生紙
- flash-jerky.svg：牛肉乾
- rank-bose.svg：耳機
- rank-phone.svg：手機
- rank-tv.svg：電視

圖片以 img 載入，不把 SVG markup 插入 DOM。若更改檔名，請一併更新 mock/cards.draft.json 的 image.src。
